# Taller-de-aplicacion

Grupo: Juan Rojas, Juan Pabon, Luisa Arévalo 

El programa inicia mostrando el menú principal con las opciones, se debe seleccionar la opción 1 para establecer un aporte mínimo y el porcentaje de retorno, con la opción 2 se registra el primer participante, que sera la raiz del árbol, los siguientes participantes se registran indicando la identificación de un participante existente, que será su padre. Una vez registrados los participantes se pueden utilizar las opciones del menu para realizar búsquedas, mostrar el árbol y consultar los cálculos, la opción 10 permite realizar pagos segun el orden del arbol y la opcion 0 finaliza el programa
